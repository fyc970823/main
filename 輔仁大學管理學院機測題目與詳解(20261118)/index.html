注意：本詳解皆使用 python 來作答，且部分程式排版可能偏醜，敬請見諒:D

1.迴文判定

寫一個程式，判斷輸入的字串是否迴文（指正著念跟倒著念都相同）。
輸出/入格式為：先輸入一個整數 ，代表之後有 筆測資，之後有 行，每行輸入一個字串，判斷該字串是否為迴文，若是，輸出 “Yes” ，否則輸出 “No” 。
這題是第一題，所以相對簡單，只要寫一個 for 迴圈，並使用 if s[i] == s[len(s)-i-1] 判斷式即可。

5.基地台影響範圍

這題主要是考二維陣列，有一個 的區域，計算基地台的覆蓋面積，同時以兩種基地台，A基地台的範圍是以自己為中心的九宮格，B基地台則是以自己為中心，向上下左右擴展兩格，影響範圍共九格的基地台。
輸出/入格式為，先輸入一個整數 ，代表之後有 筆測資，接著在每個測資中，先輸入三個整數 ,, 分別代表區域的列、行及有幾個基地台，之後有 行，每行第一個是字元，二三個是整數： ,, 分別代表基地台種類、基地台的列與行，最後輸出訊號覆蓋的總面積。
這題應該是機測中最難的一題，在保羅老師的影片中都沒這種難度的題目，這題主要是考二維陣列，來記錄訊號覆蓋的區域，跑迴圈時，若跑到了沒有覆蓋但須覆蓋的區域，就把答案變數 +1 ，同時也須注意邊界範圍，避免程式出現 list out of range 。

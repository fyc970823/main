# 1.迴文判定
寫一個程式，判斷輸入的字串是否迴文（指正著念跟倒著念都相同）。
輸出/入格式為：先輸入一個整數 $N$ ，代表之後有 $N$ 筆測資，之後有 $N$ 行，每行輸入一個字串，判斷該字串是否為迴文，若是，輸出 "Yes" ，否則輸出 "No" 。
這題是第一題，所以相對簡單，只要寫一個 `for` 迴圈，並使用 `if s[i] == s[len(s)-i-1]` 判斷式即可。
```python
for _ in range(int(input())):
    s=input()
    ok=1
    for i in range(len(s)//2+1):
        if s[i] != s[len(s)-1-i]:
            ok=0
            break
    if ok == 1: print("Yes")
    else: print("No")
```
# 2.質因數分解
寫一個程式，列出一個數字的所有質因數
輸出/入格式為：先輸入一個整數 $N$ ，代表之後有 $N$ 筆測資，之後有 $N$ 行，每行輸入一個整數，並列出該整數的所有質因數。例如輸入 $48$ 時，輸出應為 `2 2 2 2 3` 。
這題對機測來說也是簡單的題目，這題的解法可以用 `while` 迴圈，先設一個變數為 $2$ ，當該數無法整除時就加一，否則一直除下去，直到該數除到只剩一為止。
```python
for _ in range(int(input())):
    n=int(input())
    ans=[]
    p=2
    while n != 1:
        if n % p == 0:
            ans.append(p)
            n//=p
        else:
            p+=1
    print(*ans)
```
# 3.雞兔同籠
非常一般的小學題目，沒什麼好說的。
輸出/入格式為，先輸入一個整數 $N$ ，代表之後有 $N$ 筆測資，之後有 $N$ 行，每行輸入兩個整數，分別為動物的總數與腳的總數，輸出雞跟兔分別有幾隻，雞跟兔至少都要有一隻，否則其中一種數量為 `0` 或計算錯誤接輸出 `False` 。
這題是要解二元一次方程式，但用一般的解法在程式中較為麻煩，所以這題要用到一個在高中教的克拉瑪公式，公式如下：
若
$$
a_1 x + b_1 y = c_1
$$
$$
a_2 x + b_2 y = c_2
$$
則
$$
x = \frac{\begin{vmatrix} c_1 & b_1 \\ c_2 & b_2 \end{vmatrix}}{\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix}}, \qquad
y = \frac{\begin{vmatrix} a_1 & c_1 \\ a_2 & c_2 \end{vmatrix}}{\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix}}
$$
雞兔同籠的二元一次方程式如下：
$$
x + y = n \\
$$
$$
2x + 4y = f
$$
這題需要額外注意的是，除了計算結果為負數以外，當腳的總數為奇數時，計算結果不會是整數，所以需要多加一個判斷式（結果除以餘數等於0）來判斷。
```python
for _ in range(int(input())):
    n,f=map(int,input().split()) #n為動物總數，f為腳的總數
    c = (n*4 - 1*f) / (2) #2=(1*4-1*2)
    r = (1*f - n*2) / (2)
    if r > 0 and c > 0 and r % 1 == 0 and c % 1 == 0:
        print(int(c),int(r))
    else:
        print(False)
```
# 4.有幾個PRAY
這題要計算在一個字串中，有幾個 $PRAY$ 藏在裡面，例如一長度為九的字串 `PRAYDKAQY` 中，就有三種 $PRAY$ 的位子：$(0,1,2,3),(0,1,2,8),(0,1,6,8)$ 。
輸出/入格式為，先輸入一個整數 $N$ ，代表之後有 $N$ 筆測資，之後有 $N$ 行，每行輸入一個字串，並輸出該字串中藏了幾個 $PRAY$ 。
這題本上面還說須注意長度為700的字串避免TLE，結果我寫了一個四重迴圈 `AC` ，那就這樣吧:D。
先來一個硬爆的方法。
```python
for _ in range(int(input())):
    s=input()
    ans=0
    for p in range(len(s)):
        if s[p] == 'P':
            for r in range(p+1,len(s)):
                if s[r] == 'R':
                    for a in range(r+1,len(s)):
                        if s[a] == 'A':
                            for y in range(a+1,len(s)):
                                if s[y] == 'Y':
                                    ans += 1
    print(ans)
```
但最佳解應該是用DP，時間複雜度最佳。
```python
t = "PRAY"
for _ in range(int(input())):
    s = input()
    dp = [1,0,0,0,0]
    for c in s:
        for i in range(3,-1,-1):
            if c == t[i]:
                dp[i+1] += dp[i]
    print(dp[4])
```
# 5.基地台影響範圍
這題主要是考二維陣列，有一個 $R * C$ 的區域，計算基地台的覆蓋面積，同時以兩種基地台，A基地台的範圍是以自己為中心的九宮格，B基地台則是以自己為中心，向上下左右擴展兩格，影響範圍共九格的基地台。
輸出/入格式為，先輸入一個整數 $N$ ，代表之後有 $N$ 筆測資，接著在每個測資中，先輸入三個整數 $R$,$C$,$T$ 分別代表區域的列、行及有幾個基地台，之後有 $T$ 行，每行第一個是字元，二三個是整數： $D$,$M$,$N$ 分別代表基地台種類、基地台的列與行，最後輸出訊號覆蓋的總面積。
這題應該是機測中最難的一題，在保羅老師的影片中都沒這種難度的題目，這題主要是考二維陣列，來記錄訊號覆蓋的區域，跑迴圈時，若跑到了沒有覆蓋但須覆蓋的區域，就把答案變數 `+1` ，同時也須注意邊界範圍，避免程式出現 `list out of range` 。
```python
def A(m,n):
    global l,ans
    for i in range(m-1,m+2):
        for j in range(n-1,n+2):
            if 0<=i<len(l) and 0<=j<len(l[0]) and l[i][j]==0:
                l[i][j]=1
                ans+=1

def B(m,n):
    global l,ans
    for i in range(m-2,m+3):
        if 0<=m<len(l) and l[i][n]==0:
            l[i][n]=1
            ans+=1
    for i in range(n-2,n+3):
        if 0<=i<len(l[0]) and l[m][i]==0:
            ans+=1
            l[m][i]=1

for _ in range(int(input())):
    ans=0
    r,c,t=map(int,input().split())
    l=[[0]*c for _ in range(r)]
    for i in range(t):
        d,m,n=(input().split())
        if d == 'A':
            A(int(m),int(n))
        else:
            B(int(m),int(n))
    print(ans)
```

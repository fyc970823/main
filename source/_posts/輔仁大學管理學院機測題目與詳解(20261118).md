# 1.迴文判定
寫一個程式，判斷輸入的字串是否迴文（指正著念跟倒著念都相同）。
輸出/入格式為：先輸入一個整數 $N$ ，代表之後有 $N$ 比測資，之後有 $N$ 行，每行輸入一個字串，判斷該字串是否為迴文，若是，輸出 "Yes" ，否則輸出 "No" 。
這題是第一題，所以相對簡單，只要寫一個 $for$ 迴圈，並使用 $if s[i] == s[len(s)-i-1]$ 判斷式即可。
```python
for _ in range(int(input())):
    s=input()
    ok=1
    for i in range(len(s)//2+1):
        if s[i] != s[len(s)-1-i]:
            ok=0
            break
    if ok == 1: print("Yes")
    else: print("No")
```
# 2.質因數分解
寫一個程式，列出一個數字的所有質因數
輸出/入格式為：先輸入一個整數 $N$ ，代表之後有 $N$ 比測資，之後有 $N$ 行，每行輸入一個整數，並列出該整數的所有質因數。例如輸入 $48$ 時，輸出應為 $2,2,2,2,3$ 。
這題對機測來說也是簡單的題目，這題的解法可以用 $while$ 迴圈，先設一個變數為 $2$ ，當該數無法整除時就加一，否則一直除下去，直到該數除到只剩一為止。
```python
for _ in range(int(input())):
    n=int(input())
    ans=[]
    p=2
    while n != 1:
        if n % p == 0:
            ans.append(p)
            n//=p
        else:
            p+=1
    print(*ans)
```

a_1 x + b_1 y + c_1 z = d_1 \\
a_2 x + b_2 y + c_2 z = d_2 \\
a_3 x + b_3 y + c_3 z = d_3
\end{cases}
\]

\begin{cases}
a_1 x + b_1 y = c_1 \\
a_2 x + b_2 y = c_2
\end{cases}
\begin{aligned}
\Delta &= \begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix} = a_1 b_2 - a_2 b_1 \\[0.8em]
\Delta_x &= \begin{vmatrix} c_1 & b_1 \\ c_2 & b_2 \end{vmatrix} = c_1 b_2 - c_2 b_1 \\[0.8em]
\Delta_y &= \begin{vmatrix} a_1 & c_1 \\ a_2 & c_2 \end{vmatrix} = a_1 c_2 - a_2 c_1
\end{aligned}
x = \frac{\Delta_x}{\Delta}, \quad y = \frac{\Delta_y}{\Delta}

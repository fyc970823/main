# 1.迴文判定
寫一個程式，判斷輸入的字串是否迴文（指正著念跟倒著念都相同）。
輸出/入格式為：先輸入一個整數 $N$ ，代表之後有 $N$ 比測資，之後有 $N$ 行，每行輸入一個字串，判斷該字串是否為迴文，若是，輸出 "Yes" ，否則輸出 "No" 。
這題是第一題，所以相對簡單，只要寫一個 $for$ 迴圈，並使用 $if s[i] == s[len(s)-i-1]$ 判斷式即可。
```python
for _ in range(int(input())):
    s=input()
    ok=1
    for i in range(len(s)//2+1):
        if s[i] != s[len(s)-1-i]:
            ok=0
            break
    if ok == 1: print("Yes")
    else: print("No")
```
# 2.質因數分解
寫一個程式，列出一個數字的所有質因數
輸出/入格式為：先輸入一個整數 $N$ ，代表之後有 $N$ 比測資，之後有 $N$ 行，每行輸入一個整數，並列出該整數的所有質因數。例如輸入 $48$ 時，輸出應為 $2,2,2,2,3$ 。
這題對機測來說也是簡單的題目，這題的解法可以用 $while$ 迴圈，先設一個變數為 $2$ ，當該數無法整除時就加一，否則一直除下去，直到該數除到只剩一為止。
```python
for _ in range(int(input())):
    n=int(input())
    ans=[]
    p=2
    while n != 1:
        if n % p == 0:
            ans.append(p)
            n//=p
        else:
            p+=1
    print(*ans)
```
# 3.雞兔同籠
非常一般的小學題目，沒什麼好說的。
輸出/入格式為，先輸入一個整數 $N$ ，代表之後有 $N$ 比測資，之後有 $N$ 行，每行輸入兩個整數，分別為動物的總數與腳的總數，輸出雞跟兔分別有幾隻，雞跟兔至少都要有一隻，否則其中一種數量為 `0` 或計算錯誤接輸出 $False$ 。
這題是要解二元一次方程式，但用一般的解法在程式中較為麻煩，所以這題要用到一個在高中教的克拉瑪公式，公式如下：
$$
\begin{cases}
a_1 x + b_1 y = c_1 \\
a_2 x + b_2 y = c_2
\end{cases}
$$
$$
x = \frac{\begin{vmatrix} c_1 & b_1 \\ c_2 & b_2 \end{vmatrix}}{\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix}}, \qquad
y = \frac{\begin{vmatrix} a_1 & c_1 \\ a_2 & c_2 \end{vmatrix}}{\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix}}
$$
雞兔同籠的二元一次方程式如下：
$$
\begin{cases}
x + y = n \\
2x + 4y = f
\end{cases}
$$
這題需要額外注意的是，除了計算結果為負數以外，當腳的總數為奇數時，計算結果不會是整數，所以需要多加一個判斷式 $if r % 1 == 0$ 來判斷。
```python
for _ in range(int(input())):
    n,f=map(int,input().split()) #n為動物總數，f為腳的總數
    c = (n*4 - 1*f) / (2) #2=(1*4-1*2)
    r = (1*f - n*2) / (2)
    if r > 0 and c > 0 and r % 1 == 0 and c % 1 == 0:
        print(int(c),int(r))
    else:
        print(False)
```
